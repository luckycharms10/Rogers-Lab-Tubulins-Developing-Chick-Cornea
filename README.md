# Rogers-Lab-Tubulins-Developing-Chick-Cornea

Raw fluorescence data repository for study "A developmental resource mapping tubulin isotype deployment during corneal morphogenesis"

Fluorescence Intensity folder:
- consists of raw fluorescence from ImageJ and calculated CTCF values for all measurements across cell types across stages
- CTCF values were used to plot relative fluorescence intensity

Apicobasal Fluorescence Analysis folder:
- consists of raw matrices generated from straightened cell layers across stages
